# 卡片插画 · Card illustrations

把 AI 生成的插画放在这个文件夹里，网站会自动使用；没有图片时显示简洁图标作为占位。

- 文件名：`card-01.png` 到 `card-12.png`（编号对应 `cards.js` 里卡片的顺序）
- 尺寸：方形 1024×1024，PNG
- 放好后刷新网页即可，不需要改代码
